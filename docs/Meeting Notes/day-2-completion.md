## Challenges Faced & Solutions

### Challenge 1: Initial Clone Error

**Problem:** Forgot to type "git clone" before URL
**Error Message:** `'https' is not recognized`
**Solution:** Used complete command `git clone [URL]`
**Lesson:** Always include the command before arguments

### Challenge 2: VS Code Not Showing Project

**Problem:** Left sidebar empty after opening VS Code
**Solution:** Used File > Open Folder and selected correct folder
**Lesson:** Must explicitly open folder in VS Code

### Challenge 3: Desktop Folder Not Created

**Problem:** Clone command didn't create folder on Desktop
**Cause:** Was not in Desktop directory in Command Prompt
**Solution:** Used `cd Desktop` before clone command
**Lesson:** Always verify current directory before operations
