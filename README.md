## Project Overview

An AI-powered recruitment platform featuring:
- Automated skill-based assessments
- AI-conducted interviews with video recording
- Behavior monitoring during tests
- Smart job matching and notifications
- Multi-panel system (Job Seeker, Job Provider, Admin)

---

## Tech Stack

### Frontend
- React.js with Vite
- Tailwind CSS
- React Router

### Backend
- Node.js with Express
- MongoDB (assessments, questions)
- PostgreSQL (user data, jobs)

### AI/ML Features
- Face detection (face-api.js)
- Video recording (MediaRecorder API)
- Basic behavior monitoring

### Deployment
- Frontend: Vercel
- Backend: Render/Railway
- Database: MongoDB Atlas + Supabase

4. **Assessment Engine** - Dynamic quiz generation, auto-grading
5. **AI Interview Module** - Question bank, video recording
6. **Behavior Monitor** - Webcam tracking, anomaly detection
7. **Notification System** - Job alerts, candidate matching
